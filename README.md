### Install

**Windows**
1. Download the ZIP from the table above.
2. Extract the complete ZIP to a folder.
3. Launch the game's executable from the extracted folder; keep the accompanying Unity files together.

**Android**
1. Download the APK matching your device's architecture.
2. Open the APK on your Android device and follow the installation prompts.
3. Android may ask you to allow installation from the app used to open the APK. Only install files you trust.

**Before uninstalling or reinstalling:** Use the game's **save export** feature to back up your progress, then keep the exported backup somewhere safe. You can restore it through **save import**.

## 🛠️ What's new in v0.1.46?

- **Safer item drops:** Dropped items avoid nearby walls and scenery. If no clear spot is available, the item stays in inventory or equipment.
- **Door interactions:** The normal interact control opens nearby doors. Closed doors can be interacted with without their own colliders blocking access, while unrelated walls and fences still block interaction.
- **Mobile interaction priority:** Touch controls prioritize nearby loot, doors and usable objects instead of simply selecting the first item in the list.
- **Bandage treatment:** Co-op healing still restores **25 HP** and now also stops bleeding. Bleeding players can be treated at full health, healthy players don't waste bandages, and each successful treatment consumes one bandage.
- **Automatic-fire audio:** Guests hear every confirmed gunshot, even when multiple shots arrive in one network update.
- **Suppressed weapon audio:** Guests receive the correct suppressed gunshot sounds.
- **Duplicate protection:** Repeated network updates and effect IDs no longer replay the same sound, recoil or visual effect twice.
- **Multiplayer compatibility:** Audio networking now uses **protocol 5**, preventing incompatible older clients from joining.
