### Install

**Windows**
1. Download the ZIP from the table above.
2. Extract the complete ZIP to a folder.
3. Launch the game's executable from the extracted folder; keep the accompanying Unity files together.

**Android**
1. Download the APK matching your device's architecture.
2. Open the APK on your Android device and follow the installation prompts.
3. Android may ask you to allow installation from the app used to open the APK. Only install files you trust.

**Before uninstalling or reinstalling:** Use the game's **save export** feature to back up your progress, then keep the exported backup somewhere safe. You can restore it through **save import**.

## 🛠️ What's new in v0.1.43?

- **Movement and mobile aim:** Consistent walking speed in every direction, including diagonals. Mobile touch controls no longer display a mouse cursor or let mouse position steer aim.
- **Melee and ranged targeting:** Independent melee/ranged auto-aim toggles, improved melee targeting and target switching, optional melee cursor ring/marker, and centered auto-aim reticle. Controller free aim has no distance cap.
- **Controller inventory:** A for action menus, double-A to transfer, X for primary weapon, double-X for secondary weapon; X on consumables assigns a quick-use slot. Double-X in raids toggles configured zoom without triggering reload.
- **Controller navigation:** Better adjacent-slot movement, D-pad support, scrolling selected items into view, and virtual cursor input-ownership fixes.
- **Cinematic mode:** New Display option, toggled using **F8** or a **three-finger gesture**, to hide gameplay HUD and indicators until a menu opens.
- **Combat and stealth:** Doubled previous cooldowns for Slash abilities; undetected attacks prompt enemies to search instead of instantly locating the shooter.
- **NPCs and visibility:** Repaired seven invisible NPC definitions and improved low-cover visibility.
- **UI and loot:** Breakdown preview shows item reward icons and quantities; combat gasmask removed from all Forest Outskirts chest tiers.
- **Rendering:** Corrected platform setup and lifetime of runtime post-processing resources.
